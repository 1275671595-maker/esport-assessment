第一步：注册 GitHub + 创建仓库

填写用户名、邮箱、密码，完成注册（如果已有账号，跳过此步）

2创建新仓库

登录后打开 https://github.com/new

按以下填写：

创建后会看到一个页面，记住你的仓库地址，格式类似：

https://github.com/你的用户名/esport-assessment.git

第三步：注册 Render + 部署

4注册 Render 账号

打开 https://render.com

点击右上角 Sign Up，选择 GitHub 登录（推荐，自动关联）

授权 Render 访问你的 GitHub（点击 Authorize Render）

5创建 Web Service

登录后点击右上角 New + → 选择 Web Service

在列表中找到你的仓库 esport-assessment，点击 Connect

如果列表中没有，点击 Configure account 给 Render 更多权限

6配置部署参数

Render 会自动读取项目中的 render.yaml，大部分参数会自动填好。检查以下设置：

Name: esport-assessment （或任意名称） Runtime: Node Build Command: npm install Start Command: node server.js Instance Type: Free （免费版）

其他保持默认，滚动到页面底部，点击 Deploy Web Service

等待 1-3 分钟，状态从 Building → Live

部署成功后，页面顶部会显示公网地址，格式类似：
https://esport-assessment.onrender.com
这个地址就是考官和考生最终访问的网址！

第四步：验证部署

7测试公网访问

打开你的 Render 部署地址（如 https://esport-assessment.onrender.com）

双设备测试：用手机打开网址登录考生，用电脑打开网址登录考官，考生提交预约后考官端 10 秒内自动刷新看到新单。

常见问题

Q: Render 免费版有什么限制？

免费版服务在 15 分钟无访问后会自动休眠，下次访问时需要等 30-60 秒冷启动。对于考核预约这种低频使用场景完全够用。如果需要 7×24 不休眠，可以升级到 Starter 计划（$7/月）。

Q: 数据会丢失吗？

正常运行期间数据保存在服务器上不会丢失。但如果 Render 重新部署（比如你更新了代码），data.json 会被重置。如果需要永久保存数据，建议后续升级为 PostgreSQL 数据库（Render 免费提供 90 天）。

Q: 可以不用 GitHub 吗？

可以。替代方案：注册 Railway.app，安装 Railway CLI（npm i -g @railway/cli），在项目目录执行 railway up 即可直接部署，无需 GitHub。

Q: 推送代码时报错怎么办？

# 如果报错 "failed to push some refs" git pull origin main --allow-unrelated-histories git push -u origin main # 如果报错 "remote origin already exists" git remote remove origin git remote add origin https://github.com/你的用户名/esport-assessment.git git push -u origin main

Q: Render 部署失败怎么办？

在 Render 部署页面点击 Logs 查看错误日志。最常见的问题是 npm install 失败，确认 package.json 中的依赖正确。如果遇到其他问题，把错误日志发给我，我帮你排查。
